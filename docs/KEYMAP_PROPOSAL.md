# 键位映射提案 v1 — 待用户审阅

**本文件只是规划，以下映射尚未写入RTL。当前测试版仅支持A和板载KEY1。**
建议先把已有声音接上，再逐步做滑音/颤音；暂不铺满所有品位。保留TTP229和板载键作为另一输入来源。

## 1. 统一操作

| 键 | 拟议功能 | 操作约定 |
|---|---|---|
| F1 / F2 | 钢琴 / 电吉他模式 | 按下沿切换；清除待发事件、平滑结束旧音；不自动发声 |
| Esc | 紧急全制音 | 最高优先级，清空排队/扫弦/延音/滑音状态 |
| Space | 普通平滑制音 | 吉他中用于节奏断奏；钢琴中结束延音 |
| F3 | 吉他清音/过载 | 只切效果，不触发E2或其它音 |
| F4 | 混响开关 | 沿用已有混响，平滑切换 |
| F5 / F6 | 演示1 / 演示2开始停止 | 预留，先完成手动演奏后接入 |
| 小键盘1 / 2 / 3 | 弱 / 中 / 强拨奏预设 | 锁存到下一次起音，建议0.55/0.78/1.00为试听起点 |
| 左Shift | 临时重音 | 按住时提高下一次触发力度，防溢出；不是压力检测 |
| 小键盘+ / − | 总音量增减 | 步进加平滑，独立于起音力度，不改变失真前驱动量 |
| Z / X | 当前选音区下/上八度 | 首期可只开放钢琴；边界限幅，改下一次音，不篡改正在响的音 |
| ← / → | 连续向下/向上弯音 | 首期吉他主奏，默认±2半音；按住逐步到目标，松开平滑回中 |
| V | 颤音 | 按住开启LFO，松开平滑撤去 |
| B | 连奏滑音模式开关 | 新目标音到来时平滑变频，不是改一次音高立即跳变 |
| PageUp / PageDown | 滑音时间加/减 | 初值80ms，范围20～300ms仅是建议，待试听 |

Fn、Windows、PrintScreen、Pause、媒体组合键不承担关键演奏功能。
NumLock不应改变物理小键盘按键的演奏含义：按usage映射而非PC产生的字符；上线前实测TX35两种NumLock状态。

允许和弦同时按，不把按键保持/USB重复报告当再次敲击。标准参考见使用阅读中的USB-IF链接。

## 3. 电吉他：左手选音，右手组织节奏

| 左手单弦键 | 弦号 | 音名 | MIDI参考 |
|---|---:|---|---:|
| A | 6 | E2 | 40 |
| S | 5 | A2 | 45 |
| D | 4 | D3 | 50 |
| F | 3 | G3 | 55 |
| G | 2 | B3 | 59 |
| H | 1 | E4 | 64 |

按下拨一次；保持不自动连拨；松开默认让拨弦自然衰减，Space/Ctrl负责制音。

| 键 | 和弦选择/动作 | 内容 |
|---|---|---|
| Q | 选择E5强力和弦 | E2+B2+E3 |
| W | 选择G5强力和弦 | G2+D3+G3 |
| E | 选择A5强力和弦 | A2+E3+A3 |
| R | 选择D5强力和弦 | D3+A3+D4 |
| J | 下扫 | 根音→五度→八度，初期约8ms弦间隔 |
| K | 上扫 | 八度→五度→根音，初期约6ms弦间隔 |
| L | 齐奏 | 同一音频采样时刻逻辑触发三声部 |
| 左Ctrl | 掌根闷音 | 按住时新拨弦使用短包络；与Space全制音不同 |

这里E5/G5/A5/D5指**根音+纯五度的强力和弦名**，不是MIDI的第五组单音。
Q/W/E/R只选和弦，不响；J/K/L发声并锁存当次和弦。默认E5。三音扫弦不是六根弦全扫。
G2/A3/D4在主工程演示相关参数中可见，正式映射前需核对音符索引和资源，不能仅相信旧注释。
J/K快速交替的调度不能静默丢事件；新扫弦是否中止旧扫弦需有明确队列/替换策略，建议短队列+溢出计数，制音立即取消全部。

## 4. 表情作用对象与冲突规则

- 第一阶段只让弯音/滑音/颤音作用于吉他“当前主奏声部”，不自动扭曲正在响的和弦；后续再提供全体音高控制。
- 连奏滑音模式建议单声部、最后按键优先；首音正常拨弦，后续目标保持相位连续、按连奏策略保留包络。与通常六弦拨奏模式分开。
- ←与→同时按视为中性，松开后回中。V可叠加弯音，但所有频率倍率限幅。
- 左Shift重音在触发时锁存；全局音量实时平滑。不把音量、起音力度、失真驱动混成一个参数。
- 模式/映射切换先释放旧声部；已经按住的键不自动补触发，需先松开再按。Esc优先于任何音符。
- TTP229与USB共存时标记输入来源，避免一个来源松开误释放另一个来源按住的同音。
- 按键数量不等于发声槽数量。增加键位优先复用声部池，不再为每个新键增加一个永久槽。

## 5. 实施前需要审阅的四项

1. 钢琴A/W/S/E黑白键布局是否顺手？
2. 吉他A～H六弦、J/K/L节奏是否接受？
3. Q/W/E/R只选和弦、J/K/L才发声是否接受？
4. Space制音、Ctrl闷音/延音、方向键弯音是否接受？

用户确认前，只维护此文档，不修改乐器键位RTL。

## 附：实现时需用的控制键usage

Keyboard/Keypad页0x07：Esc=29、Space=2C、F1～F6=3A～3F、Z=1D、X=1B、V=19、B=05、PageUp=4B、PageDown=4E、Right=4F、Left=50、小键盘1/2/3=59/5A/5B、小键盘+=57、−=56（均十六进制）。左Ctrl/左Shift是报告byte0的bit0/bit1，不占普通六键槽；等价usage E0/E1。
这只是标准码参考，必须用本机TX35实际报告核对再实施，特别是Fn/NumLock相关键。
